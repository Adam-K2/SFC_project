# Regression task folder README
## Overview  
This folder contains all source code related to the **regression tasks** in the project.  
Two separate tasks are included:

- **energy.py** – regression task for energy prediction  
- **temperature.py** – regression task for temperature prediction  

Both scripts support **training and evaluation**.

---

## Running the scripts  
You can run each task directly:

```bash
python energy.py
python temperature.py
```
Training is generally fast.  
For the energy regression task, the Transformer model may take around 10 minutes to train depending on hardware.

## Pretrained models
Pretrained model checkpoints can be downloaded from the provided Google Drive (**google_drive.txt**) link due to repository size limitations.
